# BloomInsight 🔍🌱

> **Precision Insights. Blooming Performance.**
> 社群廣告成效診斷與預算最佳化專案（Power BI / DAX）

---

## 專案簡介

隨著 Facebook、Instagram、TikTok 等社群平台演算法快速迭代、隱私權政策持續調整，傳統「廣灑預算」的投放模式早已失效。BloomInsight 以數據驅動（Data-Driven）的方式重新檢視社群廣告成效，透過互動式儀表板診斷受眾流失點、素材 ROI 與獲客成本，找出可以大幅提升投報率的黃金投放組合。

---

## 現況與挑戰

現今數位行銷普遍面臨三大痛點：

- **競價成本（CPC/CPA）飆升** — 受眾注意力碎片化，流量競價日益激烈，企業獲客成本持續攀升。
- **流量「點擊多、轉換少」** — 廣告文案雖能吸引點擊，但受眾若非精準目標群，將產生大量無效轉換流失。
- **預算配置缺乏數據佐證** — 多數行銷決策仍仰賴主觀經驗，缺乏跨受眾與素材維度的動態 ROI 評估模型。

## 三大核心商業問題

為打破無效投放的惡性循環，本專案聚焦三個核心問題，作為預算重新配置的依據。

### 1. 受眾流失漏斗（Funnel Optimization）

剖析「曝光 → 點擊 → 轉換」各關卡的流失率，釐清受眾是**點擊前就不感興趣**（CTR 低），還是**點擊後無購買意願**（ROAS 低），以精準優化投放策略。

### 2. 素材與版位 A/B Testing 評估

比較影片（Video）、圖片（Image）、輪播（Carousel）等不同廣告形式的 CPC 與 CPA 表現，識別「高成本、低回報」的劣質素材，停止預算浪費。

### 3. 受眾興趣與競價效率（Targeting）

交叉分析受眾畫像（年齡、性別）與興趣標籤（Interests），定位高投報率的藍海黃金受眾群，實現預算效益極大化。

## 專案實作（STAR 架構）

**核心專長｜社群廣告成效診斷與預算最佳化（Power BI / DAX）**

| 階段 | 內容 |
| --- | --- |
| **S** — Situation（背景） | 為優化社群媒體廣告投放成效，針對多檔社群廣告活動數據進行探索性分析與轉化診斷。 |
| **T** — Task（任務） | 評估受眾流失點、素材 ROI 及獲客成本，提供預算重新配置的依據。 |
| **A** — Action（行動） | 運用 DAX 撰寫動態加權指標，建立 5 頁式 Power BI 動態儀表板，並透過散佈圖與矩陣熱力圖定位黃金受眾與高效素材組合。 |
| **R** — Result（成果） | 產出可互動的廣告戰情室，識別高成本無效受眾，並找出高CTR的素材投放策略。 |
